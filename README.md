## ⚔️ Juggernaut

**Juggernaut** is a modular, general-purpose Discord bot written in **TypeScript**.  
The project is currently in **early development**.

> ⚠️ **Important:**  
> Active development happens on the **`dev` branch**.  
> The `main` branch is not yet production-ready.

👉 **Go to [development branch](https://github.com/Pietruszkaa/Juggernaut/tree/dev)**  


---

## 📌 Current Focus

- Core bot architecture
- Modular command & event system
- Web dashboard
- Per-guild configuration
